# MarkNav Manual Navigation

Standalone T1 + FLAIR target marking pathway for manual target marking and DICOM navigation export.

## Download

Download the latest zip from the **Releases** page:

https://github.com/epilepsyassociates-creator/marknav-manual-navigation/releases/latest

## Quick Start

1. Download and unzip `MarkNav_Manual_Navigation_CLEAN_SEQUENCED_20260425.zip`.
2. Open the `MarkNav_RELEASE` folder.
3. Read `00_START_HERE_READ_ME_FIRST.txt`.
4. Run the installer for your operating system.
5. Run MarkNav.

## Notes

- No MATLAB is required.
- ITK-SNAP must be installed separately.
- DICOM export refuses to run if `manual_target_mask.nii` is empty.
